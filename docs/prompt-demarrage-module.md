# Prompt de démarrage — Portfolio interactif (candidature bourse d'excellence)

À copier-coller dans l'agent IDE **au tout début de chaque nouvelle session**, avant d'attaquer un module. Complète la dernière ligne avec le module du jour.

---

```
Avant de développer quoi que ce soit, prends connaissance des documents suivants et attends ma confirmation avant de coder :

1. Lis intégralement AGENTS.md à la racine du projet — ce sont les règles permanentes
   (méthode de travail, décisions à ne jamais prendre seul, style de commentaires attendu,
   stack imposée).
2. Lis le cahier des charges fonctionnel détaillé (Cahier_des_Charges_Portfolio_Detaille) :
   repère le module sur lequel je vais te demander de travailler aujourd'hui, relis
   attentivement sa section "Fonctionnalités détaillées" + "Règles de gestion", ainsi que
   le modèle de données (section 4) et la charte graphique (section 6), qui s'appliquent
   à tous les modules sans exception.
3. Regarde l'état actuel du code déjà écrit dans le repo (structure de dossiers, fichiers
   déjà présents dans data/, lib/, components/, app/) pour ne rien recréer ni contredire
   ce qui existe déjà.

Une fois ces trois lectures faites, fais-moi un résumé en 5-6 lignes maximum :
- ce que tu as compris du module qu'on va développer aujourd'hui,
- les sous-couches concernées (donnée / composant — ce projet n'a pas de vrai backend
  ni de base de données, cf. AGENTS.md),
- les règles de gestion spécifiques à respecter pour ce module,
- toute question ou ambiguïté que tu identifies avant de commencer.

Ne commence AUCUN développement avant que je valide ce résumé. Une fois validé, on avance
fonctionnalité par fonctionnalité, une sous-couche à la fois (donnée → composant), avec un
plan proposé avant chaque écriture de code — jamais de code sans plan validé au préalable.
Après chaque livraison : liste-moi explicitement les cas limites non gérés, sans attendre
que je les demande.

Le module sur lequel on travaille aujourd'hui est : [À COMPLÉTER — ex. "Module 4 — Galerie
de projets"]
```
